ESP32-S3 SRAM 内存映射详细报告
===========================================

## 1. 总体内存架构

ESP32-S3的SRAM总容量：512KB
- 内部SRAM: 512KB (分为IRAM和DRAM)
- RTC Fast Memory: 8KB (RWX)  
- RTC Slow Memory: 8KB (RW)
- 外部PSRAM: 8MB (通过MMMU映射)

## 2. 内部SRAM映射 (512KB)

### IRAM (Instruction RAM) - 指令存储
- 地址范围: 0x40374000 - 0x403E0000
- 大小: ~349KB (计算值)
- 权限: RX (读+执行)
- 用途: 
  * 中断向量表 (1027 bytes)
  * 时间关键代码 (.text段, 15356 bytes)
  * 启动代码
  * ESP-IDF系统代码

### DRAM (Data RAM) - 数据存储  
- 地址范围: 0x3FC88000 - 0x3FCF0000
- 大小: ~333KB (计算值)
- 权限: RW (读+写)
- 用途:
  * 全局变量 (.data段)
  * 未初始化变量 (.bss段)
  * 运行时堆栈
  * 动态内存分配

### D/IRAM 共享区域 (416KB)
- 指令视角: 0x40378000 - 0x403E0000 (416KB)
- 数据视角: 0x3FC88000 - 0x3FCF0000 (416KB)
- 特性: 可配置为IRAM或DRAM使用
- 当前使用: 主要作为DRAM使用

## 3. 特殊内存区域

### RTC Fast Memory (8KB)
- 地址: 0x600FE000 - 0x60100000
- 权限: RWX
- 特性: 深度睡眠时保持数据
- 用途: RTC子系统和ULP代码

### RTC Slow Memory (8KB) 
- 地址: 0x50000000 - 0x50002000
- 权限: RW
- 特性: 深度睡眠时保持数据
- 用途: 持久数据存储

## 4. 外部内存映射

### PSRAM (8MB)
- 虚拟地址: 0x3C000020 - 0x3E000000 (32MB可寻址)
- 实际大小: 8MB
- 权限: RWX
- 特性: 通过MMMU映射，较慢访问速度
- 用途: 大量数据存储，图像缓存等

### Flash Cache
- 虚拟地址: 0x42000000 开始
- 大小: 16MB (实际Flash大小)
- 权限: RX
- 用途: 程序代码，只读数据

## 5. 当前内存使用状况

### IRAM 使用 (极度危险)
- 总容量: 16,384 bytes (16KB)
- 已使用: 16,383 bytes (99.99%)
- 剩余: 1 byte
- 状态: ⚠️ 严重溢出风险

### Flash 配置冲突
- sdkconfig.defaults: 8MB
- 实际配置: 16MB  
- 分区需求: 15MB (factory) + 其他
- 结论: 需要16MB Flash

## 6. 内存分配机制

### 链接器脚本控制
- 文件: build/esp-idf/esp_system/ld/memory.ld
- IRAM段: .text, .vectors, .literal等
- DRAM段: .data, .bss, .heap等

### 编译器属性
- IRAM_ATTR: 强制放入IRAM
- DRAM_ATTR: 强制放入DRAM  
- CONFIG_LV_ATTRIBUTE_FAST_MEM_USE_IRAM: LVGL使用IRAM

## 7. 优化建议

### 立即行动
1. 修复Flash配置冲突 (8MB -> 16MB)
2. 禁用LVGL IRAM使用
3. 移除非关键IRAM代码

### 长期优化
1. 代码审查IRAM使用
2. 利用PSRAM存储大数据
3. 优化链接器配置
